# Línea Sagrada

Galería personal para Android con la estética TVA. Hermana de Archivo 64.

- **Fecha**: línea de tiempo por año y mes; los viajes y eventos aparecen como expedientes.
- **Lugar**: país → ciudad. Las fotos sin GPS (WhatsApp, capturas) se ubican por cercanía en el tiempo y se marcan con ≈.
- **Poda**: repetidas y ráfagas, movidas, videos accidentales, comprobantes de un solo uso, capturas viejas y recibidas por WhatsApp. Nada se borra sin tu OK; todo va a la papelera de Android (30 días).
- **Sin internet**: la app no tiene permiso de red. El mapa de ciudades (GeoNames) y la lectura de texto (ML Kit) vienen adentro.

## Instalar
Cada push a `main` arma el APK en GitHub Actions y lo publica en **Releases**. Desde el celu: Releases → `LineaSagrada.apk` → instalar (la primera vez Android pide permitir instalar apps de esta fuente). Las versiones nuevas se instalan encima sin perder nada.

Datos de ciudades: GeoNames (CC BY 4.0).
